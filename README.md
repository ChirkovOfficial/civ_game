# Civ Game

Пошаговая 4X-стратегия по мотивам Civilization VI на Godot 4.7.

## Как запустить

1. Установить [Godot 4.7.2](https://godotengine.org/download) (Standard, не .NET).
2. В Godot: **Import** → выбрать файл `project.godot` из этой папки → **Import & Edit**.
3. Нажать **F5** (или ▶ справа вверху).

## Управление

| Действие | Клавиши |
|---|---|
| Выбрать юнит | ЛКМ |
| Отправить юнит | ПКМ по клетке (путь видно заранее при наведении) |
| Камера | WASD / стрелки, колесо — масштаб, зажатое колесо — перетаскивание |
| Следующий юнит | Tab |
| Пропустить ход юнита | Пробел |
| Конец хода | Enter |
| Показать всю карту | F2 |
| Новая карта | F5 |
