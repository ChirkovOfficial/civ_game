# Цивилизации

Решения владельца проекта (13.11.2026):

- У каждой цивилизации **свой набор боевых юнитов** вместо общих линий. Общие юниты из
  `data/units.json` — это «слоты» линий (сила, цена, технология); цивилизация задаёт им
  свои названия и особенности (`data/civs.json` → `units`).
- **Названия:** до эпохи Возрождения включительно — исторические/латинизированные (где
  история не дошла — фантазия). С Промышленной эры — **только вымышленные обозначения в
  кавычках**. Правило действует для всех цивилизаций, включая нейтральные заглушки.
- **Нет оружия массового поражения:** ядерных/термоядерных зарядов, ракетных шахт,
  заражения. Уран — только ресурс для атомных электростанций.
- **Нет боевой авиации:** ни истребителей, ни бомбардировщиков, ни ПВО. Гражданская
  авиация остаётся: район «Аэропорт» — туризм и переброска своих войск между аэропортами.
- Характеристики уникальных юнитов — как у слота линии; отличия — через особенности.

## Рим (базовая цивилизация)

### Особенность войск: «Все дороги ведут в Рим»
Любой римский **наземный боевой** юнит может вместо движения в этот ход проложить дорогу
на своей клетке (юнит ещё не двигался в этот ход; ход юнита заканчивается). Уровень
дороги — по эпохе державы (ГДД 3.8). Где можно: любая суша, кроме чужой территории;
во время войны с её владельцем — и на ней.

### Флот

| Линия | Римские юниты по эпохам |
|---|---|
| Ближний бой | Либурна → Дромон → Броненосец «Ромул» → Эсминец «Рем» |
| Дальний бой | Квинквирема → Сифонофор → Линкор «Капитолий» → Крейсер «Палладиум» |
| Рейдеры | Каперская либурна → Подлодка «Нептун» → Подлодка «Тритон» |
| Флагман | Флагман «Наследие Цезаря» — лечит соседние корабли, +3 к силе кораблям рядом |

### Поддержка
Таран, Осадная башня, Фабр (легионный инженер), Медикус, Обоз «Аннона»,
Корректировщик «Аргус» (+1 к дальности осадных юнитов рядом).
