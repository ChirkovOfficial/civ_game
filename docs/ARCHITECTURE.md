# Архитектура

```
core/                 симуляция (без графики)
  game.gd             Game: данные + состояние, apply_action(), порядок ходов
  data/game_data.gd   загрузка и проверка data/*.json
  hex/hex_grid.gd     гекс-сетка: odd-r, цилиндр, расстояния, линии, мировые координаты
  state/              GameState, GameMap (столбцы по клеткам), Player, Unit, GameRng
  map/map_generator.gd генератор карты
  rules/              правила: movement, pathfinder (A*), visibility (туман), yields
  ai/ai_player.gd     ИИ (пока разведка)
data/                 весь контент и баланс (JSON)
view/                 отображение и ввод (Godot-узлы)
  main.gd/.tscn       точка входа, связывает ядро и отображение
  map/                MapView, построение мешей, шейдеры (туман через текстуру)
  units_view.gd, overlay_view.gd, camera_rig.gd, hud.gd, map_style.gd (палитра, высоты)
tests/                тесты ядра (run_tests.gd + test_*.gd)
tools/                служебные скрипты: проверка скриптов, скриншоты, дымовой тест
art/                  арты художника
docs/                 GDD.md (дизайн), STATUS.md (прогресс), этот файл
```

## Поток данных

```
ввод (view) ──action──▶ Game.apply_action ──▶ меняет GameState ──▶ [события]
                                                                   │
view ◀── читает GameState и события ◀──────────────────────────────┘
ИИ ──action──▶ тот же apply_action
```

## Карта

- Клетка — индекс `row * width + col`. Осевые координаты `(q, r)` для расчётов, `r == row`.
- Направления: 0=E, 1=NE, 2=NW, 3=W, 4=SW, 5=SE. Ребро `d` клетки соединяет её вершины `d` и `d+1`.
- Реки — битовая маска рёбер на каждой клетке, ставится симметрично (`GameMap.set_river_edge`).
- Рельеф: `RELIEF_FLAT/HILLS/MOUNTAIN`. Особенность, ресурс, улучшение — строковые id.

## Отображение карты

- Террасы: верх гекса на высоте по типу клетки (`MapStyle.tile_height`), стенки к более низким соседям.
- Туман войны — текстура W×H (R: 0 не разведано, 0.5 разведано, 1 видно); у каждой вершины в UV2
  (у MultiMesh — в INSTANCE_CUSTOM) координаты её клетки. Неразведанное сплющивается в «пелену».
- Цилиндр: всё рисуется в трёх копиях со сдвигом на ширину карты; камера зациклена.
- Временная графика из примитивов; замена на арты — через `MapStyle` и меши/текстуры в `art/`.
