# Статус проекта

_Обновлено: 13.11.2026_

## Готово — веха M1 «Карта и движение» (ГДД 25.4)

- Каркас проекта Godot 4.7.2, рендерер Compatibility.
- Данные: ландшафты, особенности, все ресурсы, все юниты (ГДД 9.2), классы юнитов,
  полные деревья технологий (77) и институтов (61), константы, параметры партии.
  Проверка целостности данных (ссылки, циклы в деревьях).
- Ядро: гекс-сетка с цилиндром, детерминированный ГПСЧ, состояние с полной сериализацией.
- Генератор карты: 5 типов карт, 6 размеров; высоты, горные хребты, холмы, климат,
  побережье и озёра, реки по рёбрам гексов, особенности, континенты, ресурсы, стартовые позиции
  по правилам ГДД 1.
- Движение по ГДД 3.5: правило полного запаса ОД, реки, горы, ZOC (при войне), стэкинг,
  многоходовые маршруты A*, постоянные приказы движения.
- Туман войны с линиями обзора (холмы, лес, горы).
- Порядок ходов, простейший ИИ-разведчик.
- 3D-диорама: террасы, вода, реки, горы, леса, маркеры ресурсов, туман, камера, выбор
  и движение юнитов, предпросмотр пути с номерами ходов, панели информации.
- 32 теста ядра, дымовой тест интерфейса, инструмент скриншотов.

## Следующий шаг — веха M2 «Город-ядро» (ГДД 25.4)

1. Основание города поселенцем (ГДД 5.1), центр города, Дворец.
2. Жители и обработка клеток, пища/рост (4.1), производство и очередь (4.2, 5.3).
3. Границы и их рост за культуру (4.5, 5.2).
4. Строитель и улучшения клеток (8), доходы державы, золото.
5. Исследование технологий по дереву (21), эврики — сначала без условий.
6. Интерфейс города (экран города), отображение границ и городов на карте.
