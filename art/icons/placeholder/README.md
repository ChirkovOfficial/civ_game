# Временные иконки интерфейса

`ui_icon_sheet.png` — исходное изображение из вложения пользователя, без изменений. `view/placeholder_icons.gd` выбирает области листа через `AtlasTexture`: 14 общих значков (два ряда по семь) и 13 значков районов (семь и шесть). Размер области — 43 × 44 пикселя; размеры и координаты заданы в скрипте.

Значки районов привязаны к Кампусу, Священному месту, Военному лагерю, Гавани, Театральной площади, Коммерческому центру, Промышленной зоне, Развлекательному комплексу и нескольким жилым районам. Неочевидные соответствия пока условны. Остальные типы показывают общий шестиугольник. Исходный лист сохранён, чтобы позже можно было уточнить соответствия или заменить заглушки готовыми иконками.
