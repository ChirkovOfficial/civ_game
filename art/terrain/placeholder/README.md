# Временные деревья

`forest_sheet.png` — исходное изображение пользователя без изменений. Для леса и джунглей карта использует 12 больших деревьев из двух верхних рядов. Белый фон скрывается шейдером `view/map/shaders/forest_sprite.gdshader` при рисовании, сам PNG не редактируется.

Этот лист и построители старых 2D и 3D деревьев сохранены для повторного использования. Сейчас карта показывает флажки из `art/map_flags/` вместо деревьев. Вызовы старых построителей отключены в `view/map/map_view.gd`.
