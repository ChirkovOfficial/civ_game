# Временные деревья

`forest_sheet.png` — исходное изображение пользователя без изменений. Для леса и джунглей карта использует 12 больших деревьев из двух верхних рядов. Белый фон скрывается шейдером `view/map/shaders/forest_sprite.gdshader` при рисовании, сам PNG не редактируется.

Размещение двух или трёх деревьев на гексе детерминировано его индексом. Тундра чаще получает хвойные деревья, джунгли — тропические. Плоские изображения собраны в `MultiMesh` и учитывают туман войны. Старые 3D кроны и стволы сохранены в `view/map/map_view.gd` и включаются переключателем `use_legacy_tree_meshes`.
