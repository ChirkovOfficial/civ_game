# Текстуры биомов

`biome_atlas.png`: PNG 1774 × 887, сетка 4 × 2, сгенерирован встроенным image_gen. Полный запрос — в `PROMPT.md`.

Порядок слева направо: верхний ряд — луга, равнины, пустыня, тундра; нижний — снег, побережье, озеро, океан. Соответствие игровым типам задано в `MapStyle.BIOME_ORDER`.

Текстуры проецируются на верхние поверхности тайлов по мировым координатам. У границ подмешивается цвет соседних биомов; стенки террас сохраняют прежний материал. У воды отдельный режим того же атласа, лёд использует снежную текстуру. Туман войны применяется после текстурирования. Эти изображения — временные материалы, их можно заменить атласом с тем же порядком областей.
