# Флажки природы и ресурсов

`nature_flags.png` — сгенерированный встроенным image_gen атлас PNG RGBA, 1254 × 1254. Запрос сохранён в `PROMPT.md`. На листе 60 флагов: 45 ресурсов, 8 природных особенностей и 7 запасных вариантов.

Генератор разместил значки по 8–9 в ряду. `atlas.json` содержит фактические нормализованные области каждого флага с идентификатором из игровых данных. Код читает эти области через `view/map/nature_flags.gd`; шейдер выбирает нужный фрагмент, поворачивает плоскость к камере и учитывает туман войны.

Особенность и ресурс одного тайла показываются двумя флагами рядом. Стратегические ресурсы учитывают технологию раскрытия; неразведанные тайлы скрыты. Старые природные меши и спрайты сохранены в проекте, но не вызываются при построении карты. Игровые здания, районы, улучшения, дороги и горы используют своё отображение.
