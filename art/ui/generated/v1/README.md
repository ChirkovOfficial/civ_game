# Атлас интерфейса — вариант 1

Файл: `strategy_ui_atlas.png`, 1254 × 1254, PNG RGBA. Создан встроенным image_gen по описанию интерфейса исторической 4X-стратегии. Запросы сохранены в PROMPTS.md.

Состав: верхняя полоса ресурсов; шесть счётчиков доходов; карточки науки и институтов; городские баннеры; панели управления городом, производства и юнитов; рамка мини-карты; подсказка; районные строки; кнопки и вкладки; круглые и шестиугольные обрамления; полосы и кольца прогресса; кнопки завершения хода; служебные значки; скроллбары, чекбоксы и разделители.

Подписи и игровые числа следует выводить средствами Godot поверх графики. Атлас пока не подключён к интерфейсу.

Это графический вариант для дальнейшей подготовки ассетов. Генерация не гарантирует точную сетку, одинаковые размеры состояний и чистую альфа-границу: местами остаются цветные пиксели вокруг рамок. Перед интеграцией нужны проверка прозрачности на светлой и тёмной подложках, нарезка, разметка растягиваемых областей панелей и отдельные иконки там, где они сейчас совмещены с плашкой. Фактическое разрешение ниже запрошенных 4096 × 4096; небольшие значки не предназначены для сильного увеличения.
