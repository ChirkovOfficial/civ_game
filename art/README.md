# Папка для артов

Сюда кладутся рисунки, текстуры, иконки и заставки. Код подключит их сам — достаточно
положить файл и написать, что это и где должно появиться.

Удобная раскладка (можно создавать папки по мере надобности):

```
art/
  concept/     концепт-арты, референсы, скетчи для 3D
  textures/    текстуры ландшафта (луга, равнины, пустыня…), лучше бесшовные, 512–1024 px
  icons/       иконки ресурсов, юнитов, доходов (PNG с прозрачностью, 128–256 px)
  ui/          элементы интерфейса
  splash/      заставки и экраны загрузки
```

Форматы: PNG (с прозрачностью) или JPG для больших картинок. Имена файлов — латиницей,
без пробелов, например `grass_01.png`, `icon_wheat.png`.
